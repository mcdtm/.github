# mcdtm

Oficjalna organizacja GitHub serwera Minecraft **[mcdtm.pl](https://mcdtm.pl)**.

Tworzymy pluginy, API, usługi backendowe i infrastrukturę. Cały nasz kod jest
otwartoźródłowy — **poza sekretami**.

## Co robimy

- **Pluginy** — rozgrywka, komendy, mechaniki serwerowe.
- **API** — wspólne biblioteki i interfejsy dla naszych projektów.
- **Backend** — usługi wspierające serwer i sklep.
- **Infrastruktura** — narzędzia, deployment, automatyzacja.

Większość projektów to Java (Gradle lub Maven), ale zdarzają się też inne
technologie tam, gdzie mają sens.

## Open source, poza sekretami

Wierzymy w otwarty kod. Wszystko, co możemy pokazać światu, pokazujemy.
Sekrety — hasła, tokeny, klucze API, dane z serwera — zostają tam, gdzie
ich miejsce: poza repozytoriami.

Jeśli znajdziesz lukę bezpieczeństwa, nie zgłaszaj jej publicznie.
Zajrzyj do [SECURITY.md](SECURITY.md) i napisz do nas prywatnie.

## Chcesz pomóc?

Świetnie. Zanim zaczniesz, przeczytaj:

- **[CONTRIBUTING.md](CONTRIBUTING.md)** — jak zgłaszać błędy, proponować
  funkcje i wysyłać pull requesty.
- **[CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md)** — zasady naszej społeczności.
  Krótko: bądź spoko, krytykuj kod, nie ludzi.
- **[SECURITY.md](SECURITY.md)** — jak zgłaszać luki bezpieczeństwa.

Nie musisz być ekspertem. Jeśli coś jest niejasne — pytaj. Wolimy odpowiedzieć
na pytanie niż odrzucić pull request, który nie pasuje.

## Sklep i wsparcie

Serwer utrzymuje się ze sklepu — rangi, wyróżnienia i inne rzeczy finansują
hosting i rozwój. Dziękujemy każdemu, kto wspiera projekt.

Sprawy związane z płatnościami, zakupami i supportem załatwiamy **poza
GitHubem**. Issues i pull requesty to miejsce na kod, nie na prośby o darmowe
rangi.
